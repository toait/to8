# TOAIT SDKs Monorepo

The Main SDK of The Open Artificial Intelligence Toolkit (TOAIT) which is written in Golang. Additionally, this monorepo will contain submodule links to all SDKs for other programming languages (ECMAScript, Python, Ruby, etc.)
